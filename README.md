## ✨ Quick Import

### Option 1: Import All Skills (Recommended)

**In Lovable:**
1. Go **Settings → Skills → Add → Import from GitHub**
2. Paste: `https://github.com/yougotsam/got-skills`
3. ✅ Lovable auto-detects all 130+ skills in `/skills/` folder
4. Done! All skills imported into your workspace

**In Cursor / Claude:**
- Drop any `SKILL.md` folder into `.cursorrules/` or `.claude/skills/`
- Or symlink: `ln -s ~/got-skills/skills/tanstack-query-alternative ~/.cursorrules/`

### Option 2: Import Individual Skills

Paste into GitHub import dialog:
```
https://github.com/yougotsam/got-skills/tree/main/skills/<skill-name>
```
