# Decide — 37signals Framework

Work through a structured decision framework to think clearly about major choices.

## When to Use

Pivot decisions, hiring, pricing changes, product strategy, major investments.

## The Framework

1. Define the decision clearly (not fuzzy)
2. List reversible vs. irreversible consequences
3. Gather data (but don't over-research)
4. Consider opportunity cost
5. Trust your instincts
6. Set a revisit date

## Key Questions

- What are we really deciding?
- What would we regret NOT doing?
- Can we undo this decision?
- What's the worst outcome we can live with?
