# Got Skills — Bundled Skills Index

This repository contains five playbooks and one root routing entry point. The former 130+ inventory listed skills that are not included here.

## One combined import

Import https://github.com/yougotsam/got-skills to add the `got-skills` routing skill. It selects from the five bundled playbooks; it does not create five separate workspace skills.

## Separate imports

Paste a folder URL below into Lovable's **Settings → Skills → Add → Import from GitHub** to import that skill independently.

| Skill | Purpose | Import URL |
| --- | --- | --- |
| copywriting | Marketing page copy and CTAs | https://github.com/yougotsam/got-skills/tree/main/skills/copywriting |
| decide | Structured business and product decisions | https://github.com/yougotsam/got-skills/tree/main/skills/decide |
| tanstack-query-alternative | Client-side fetching and caching | https://github.com/yougotsam/got-skills/tree/main/skills/tanstack-query-alternative |
| supabase-rls-and-auth | Authentication and database access policies | https://github.com/yougotsam/got-skills/tree/main/skills/supabase-rls-and-auth |
| stripe-payment-webhooks | Payment event handling | https://github.com/yougotsam/got-skills/tree/main/skills/stripe-payment-webhooks |

Related-skill names inside these playbooks are external suggestions, not files included in this repository. No additional skills are fetched or installed automatically.
